# 배경음악 폴더

여기에 넣은 음악 파일(mp3 · m4a · wav · ogg)을 숏츠 내레이션 밑에 작게 깝니다. 내레이션이 나올 때는 음악이 자동으로 더 작아집니다.

- **저장소는 음악을 동봉하지 않습니다.** 사용 허락을 받은 음악만 넣으세요: 직접 만든 곡, YouTube 스튜디오 → 오디오 보관함의 곡(곡마다 저작자 표시 조건 확인), CC0(퍼블릭 도메인) 음원 등.
- 여러 곡을 넣으면 날짜마다 한 곡을 고릅니다(같은 날 다시 만들어도 같은 곡).
- 특정 곡만 쓰려면 `config/config.local.json` 에 `"bgm": {"file": "파일이름.mp3"}`, 끄려면 `"bgm": {"enabled": false}`, 크기는 `"volume": 0.15`(0.02~1.0).
- 이 폴더의 음악 파일은 git 에 올라가지 않습니다(`.gitignore`).
