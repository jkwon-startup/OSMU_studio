# 브랜드 토큰 — 숏츠 모션 카드·자막·인스타 카피 글자에 공통으로 쓰입니다.
# 바꾸려면 이 파일을 config/frame.local.md 로 복사해서 고치세요(/osmu-setup 이 만들어 줍니다).
colors:
  bg: "#0F172A"        # 모션 카드 배경
  accent: "#F59E0B"    # 강조(막대·점·숫자)
  text: "#FFFFFF"      # 본문 글자
  muted: "#94A3B8"     # 보조 글자
caption:
  color: "#FFFFFF"     # 자막 글자
  highlight: "#FFD60A" # 자막 강조 단어(숫자 등)
  stroke: "#000000"    # 자막 테두리
  size: 1.0            # 자막 크기 배율 (0.6 ~ 1.6)
font:
  bold: Pretendard-Bold.otf        # assets/fonts 안의 파일 이름 (OFL 등 배포 가능한 글꼴만)
  regular: Pretendard-Regular.otf
---

# 메모

- 색은 `#RRGGBB` 형식. 배경(bg)과 글자(text)는 밝기 차이가 커야 폰 화면에서 읽힙니다.
- 글꼴을 바꾸려면 한글이 들어 있는 글꼴 파일을 `assets/fonts/` 에 넣고 이름을 적으세요.
