# 인스타그램 피드 규칙

> 적용: `osmu-sns-editor`(인스타 모드), `osmu-visual`(3:4 이미지). 입력은 윤문된 블로그(05_blog.md), 카피(04_copy.md), 문체 프로파일(config/style-profile.local.md, 있으면).

## 목적

블로그 글을 **짧고 임팩트 있게** 재구성한다. 블로그 요약이 아니라, 피드에서 엄지를 멈추게 하는 한 장 + 캡션이다.

## 이미지 (비주얼 디렉터)

- 비율 **3:4**(1080×1440). 실사, 가로형 블로그 이미지와 같은 세계관(같은 장면·톤).
- 이미지 자체에는 글자 없음. **후킹 카피(04_copy.md 의 "인스타 이미지 위 카피", 20자 이내)를 코드로 합성**한다 — 위치 상단 또는 하단 1/3, 가독성을 위한 반투명 띠, OFL 폰트.
- 카피는 1~2줄. 글자가 피사체의 얼굴·핵심 물체를 가리지 않는다.

## 캡션 (SNS 에디터)

- **첫 문장 30자 이내**(접힘 전 노출). 04_copy.md 의 "인스타 첫 문장"을 쓰거나 페르소나에 맞게 다듬는다.
- 본문 **300~600자**. 핵심내용 5가지 중 **2~3개만** 고른다. 전부 넣지 않는다.
- 구조: 훅 1줄 → 공감 1~2줄 → 핵심 2~3개(각 1~2줄, 줄바꿈으로 호흡) → 저장·공유 유도 1줄.
- 한 줄은 짧게. 문단 사이 빈 줄 1개. 이모지는 최대 2개, 줄 머리에 쓰지 않는다.
- 블로그 메인 키워드와 틈새 키워드를 캡션 안에 자연스럽게 1회씩.
- **해시태그 3개 미만(최대 2개)**, 캡션 맨 끝 한 줄. 메인 키워드 1개 + 브랜드 또는 틈새 1개. 띄어쓰기 없는 한글 해시태그.
- 링크는 "프로필 링크" 언급으로 대체(캡션 링크는 클릭 안 됨).
- 블로그에 없는 사실·수치를 추가하지 않는다.

## 참고 계정 반영

문체 프로파일이 있으면 **말투·문장 길이·줄바꿈 리듬·CTA 방식**만 가져온다. 참고 계정의 문장·표현을 그대로 쓰지 않는다. 프로파일이 없으면 페르소나의 평소 말투(02_persona.md 10절)를 기준으로 쓴다.

## 출력 (`06_instagram.draft.md`)

```
---
image_copy: (이미지 위 카피, 20자 이내)
hashtags: ["#…", "#…"]
---
(캡션 본문. 해시태그 줄 제외)
```

## 검수 포인트

첫 문장 ≤30자 / 본문 300~600자 / 해시태그 ≤2 / 이모지 ≤2 / 핵심 2~3개만 / 블로그 밖 사실 없음 / 이미지 카피 ≤20자
