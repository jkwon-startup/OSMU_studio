# 페르소나 규칙 — 5명 도출 → 1명 자동 선택 → 상세 프로파일

> 적용: `osmu-strategist`. 입력은 리서치 노트(01_research/*.md)와 브랜드 소개, 한국 인구 분포(`rules/data/korea-distribution.md`).
> 방법론: 드림 100 · 가치 사다리(Russell Brunson) + SB7(Donald Miller). 무인 실행이므로 "사용자에게 묻기" 대신 아래 기준으로 자동 선택하고 근거를 남긴다.

## 1단계 — 페르소나 5명 도출

목표: 시장 세분화 결과로 **시장성 있는, 서로 다른 5명**.

1. 4축(인구통계 · 심리 · 행동 · 기술 친숙도)으로 시장을 나눈다. 분포 데이터에서 벗어난 비현실적 세그먼트는 만들지 않는다.
2. 세그먼트마다 대표 인물 1명을 뽑는다.
3. 시장성 · 성장성 · 경쟁 강도 · 제품-시장 적합도 4기준으로 상위 5명을 확정한다.
4. 5명은 **최소 2개 축에서 서로 구분**되어야 한다.

제약: 이름 + 구체 직업 + 거주지(시·구) 필수. "어디에 모여 있는가"(온라인 커뮤니티·오프라인 장소)를 1행 이상 명시.

출력(표):

| # | 이름 | 인구통계 | 주요 니즈 | 고통 포인트 | 자주 모이는 곳 |
|---|---|---|---|---|---|

## 자동 선택 기준 (무인 실행)

5명 중 1명을 다음 가중치로 고르고, `decisions.json` 에 넣을 근거를 2~3문장으로 쓴다.

| 기준 | 가중치 | 판단 근거 |
|---|---|---|
| 주제 적합도 | 40% | 오늘 주제의 질의의도를 가장 절실하게 가진 사람인가 (리서치 노트의 검색 의도·댓글·질문과 대조) |
| 시장성 | 25% | 분포 데이터상 세그먼트 규모, 리서치의 수요 신호 |
| 브랜드 적합도 | 20% | 브랜드 소개의 타겟·톤과 맞는가 |
| 콘텐츠 전환 가능성 | 15% | 블로그→SNS→숏츠로 변환했을 때 훅이 살아나는 사람인가 |

동점이면 주제 적합도가 높은 쪽. 선택되지 않은 4명은 표로 남겨 둔다(다음 주제에서 재활용 가능).

## 2단계 — 선택된 1명 상세 프로파일 (10섹션 모두 작성)

깊이 있는 1명 > 얕은 5명. 분량은 1단계 표의 2.5배 이상. 표면적 형용사 나열 금지 — 각 항목은 *왜 그러한지* 1단계 표와 한국 시장 맥락에서 정당화한다.
한국 고유명사(지역구 · 앱 · 플랫폼 · 브랜드 · 커뮤니티)를 적극 쓴다. 가상 이름·미국식 명칭 금지.

```
## 확정: [이름]
[한 줄 정체성 — 직업·거주·핵심 정체성을 한 호흡에]

### 1. 인구통계 심화
| 항목 | 값 |
| 나이 / 성별 | |
| 직업 / 직급 | |
| 거주지 (시·구) | |
| 가족 구성 | |
| 소득 구간 (월) | |
| 교육 수준 | |
| 주거 형태 | |
| 통근/이동 수단 | |

### 2. 심리 프로필 (OCEAN 5요인 + 핵심 가치관 3개)
- 개방성(O) / 성실성(C) / 외향성(E) / 친화성(A) / 신경성(N): 높음·보통·낮음 — 이유 1줄씩
- 핵심 가치관 3개

### 3. 하루 일과 시나리오
아침(06–09) / 오전(09–12) / 점심(12–14) / 오후(14–18) / 저녁(18–22) / 주말 — 장소·앱·브랜드 포함 1~2문장씩

### 4. 고통 포인트 시나리오 3~5개
> **[제목]** — ○요일 ○○에서 ○○할 때 ○○해서 ○○하다.
> · 빈도 / · 강도(1~5) / · 현재 회피 비용(돈·시간·감정)

### 5. 정보 탐색·의사결정 행동
- 자주 쓰는 정보 채널 5개 / 결정 근거 5개(가중치 순) / 가격 민감도 / 의사결정 속도

### 6. 소비/구매 패턴
카테고리별 월 지출(추정) / 가격대 선호 / 결제 수단 / 구매 빈도 / 환불·교환 성향

### 7. 드림 100 — 어디 모이는가
온라인 커뮤니티 5+ / 오프라인 장소 3+ / 영향력 있는 인플루언서·콘텐츠 출처 3+ (모두 실명)

### 8. 가치 사다리 위치 + 후속 오퍼
진입점(무료 리드 마그넷 / 저가 트립와이어 / 중가 코어 / 고가 백엔드) — 근거 1줄 / 다음 단계 오퍼 / 정점에서의 변환된 자아

### 9. SB7 캐릭터 정의
욕망 / 외적 문제 / 내적 문제(외적 문제 때문에 느끼는 감정) / 철학적 문제(왜 그것이 잘못인가) / 진정한 변화

### 10. 이 주제에서 페르소나가 평소 쓰는 말
- 평소 표현 3개 / 페인을 말할 때 쓰는 말 2개 / 욕망을 말할 때 쓰는 말 2개
  (카피라이터가 "마켓 랭귀지"로 쓴다 — 리서치 노트의 댓글·질문·제목에서 실제 표현을 가져올 것)
```

## 핵심내용 5가지 (같은 팀원이 이어서 작성 → `03_key_points.md`)

페르소나의 고통 시나리오·질의의도·SB7 문제에 직접 닿는 핵심내용 5가지를 뽑는다.

- 각 항목: **한 줄 제목(15자 내외) + 왜 이 페르소나가 멈춰 읽는지 1문장 + 담을 근거(리서치 노트의 사실·수치·사례, 출처 URL)**
- 5개는 서로 다른 고통 또는 단계(인지→고려→행동)를 건드린다. 같은 말을 각도만 바꿔 반복하지 않는다.
- 하나는 반드시 "환상 깨기"(기대와 현실의 차이), 하나는 "오늘 당장 할 수 있는 것"으로.
- 리서치에 근거가 없는 주장은 넣지 않는다. 근거가 약하면 "작성자 경험으로 보완 필요"라고 표시한다.
