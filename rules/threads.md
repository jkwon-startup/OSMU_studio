# 쓰레드 피드 규칙

> 적용: `osmu-sns-editor`(쓰레드 모드). 입력은 인스타 초안(06_instagram.draft.md)과 카피, 설정된 말투(config `threads_style`), 문체 프로파일.

## 목적

인스타 캡션을 **쓰레드의 대화체**로 다시 쓴다. 더 짧고, 더 말하듯이, 한 가지 생각만.

## 말투 — 설치 때 설정된 하나로 고정

| threads_style | 특징 | 예 |
|---|---|---|
| 반말 | 친구에게 말하듯. 종결 "~야", "~다", "~거든" | "블로그 하루 30분이면 된다는 말, 반은 맞고 반은 틀려." |
| 혼잣말 | 생각을 흘리듯. 주어 생략, 문장 끝 여운 | "하루 30분… 처음 2주는 1시간이었지." |
| 존댓말 | 친한 존대. "~요" 종결, 격식체(~습니다) 금지 | "하루 30분이면 된다는 말, 반만 믿으세요." |

한 글 안에서 말투를 섞지 않는다.

## 본문

- **첫 줄 25자 이내** — 04_copy.md 의 "쓰레드 첫 줄"을 말투에 맞게. 첫 줄만 보고 멈추게.
- 전체 **150~350자**, 1~4문단. 핵심내용 5가지 중 **1~2개**만.
- 문장은 짧게. 한 문단 1~2문장. 이모지 0.
- 질문으로 끝내거나(답글 유도), 한 줄 반전으로 끝낸다. "저장하세요" 같은 인스타식 CTA 금지.
- 블로그 메인 키워드 1회 포함.
- **해시태그 1개**, 맨 끝. 메인 키워드 또는 틈새 키워드.
- 블로그에 없는 사실 추가 금지. 숫자는 인스타·블로그와 동일.

## 참고 계정 반영

문체 프로파일이 있으면 어미·호흡·마무리 방식만 가져온다. 표현 복제 금지.

## 출력 (`07_threads.draft.md`)

```
---
style: 반말 | 혼잣말 | 존댓말
hashtag: "#…"
---
(본문)
```

## 검수 포인트

첫 줄 ≤25자 / 150~350자 / 해시태그 정확히 1 / 이모지 0 / 말투 하나로 일관 / 블로그 밖 사실 없음
