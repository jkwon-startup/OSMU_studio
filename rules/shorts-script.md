# 숏츠 스크립트 규칙

> 적용: `osmu-shorts`(script 모드 → produce 모드). 입력은 윤문된 블로그(05_blog.md), 카피(04_copy.md), 주제의 영상 스타일(topic.json `video_style`: photoreal | motion), 문체 프로파일(숏츠 참고 계정, 있으면).

## 규격

- 기본 세로 9:16(1080×1920), 30fps. 설치자 설정 `shorts_aspect` 로 1:1(1080×1080)·16:9(1920×1080)도 가능. 기본 **30초**(config `shorts_duration_s`, 20~45초).
- 내레이션 분량 **약 7자/초** → 30초 ≈ 210자(공백 포함). ±10% 안에서.
- 구어체. 눈으로 읽는 글이 아니라 **말로 했을 때 자연스러운 문장**. 한 문장 15자 안팎, 최대 25자.
- 숫자는 `tts_text` 에서 한글로 풀어 쓴다("30분" → "삼십 분", "2026년" → "이천이십육 년"). 화면 자막(`beats[].caption`)은 숫자 그대로.

## 구조 (beats)

| 구간 | 시간 | 내용 |
|---|---|---|
| 훅 | 0~3초 | 04_copy.md 의 "숏츠 훅"(15자 이내). 질문·반전·숫자 중 하나. 주제명 말하지 않기 |
| 문제 | 3~8초 | 페르소나의 고통 시나리오 1개를 한 장면으로 |
| 핵심 | 8~24초 | 핵심내용 5가지 중 **2~3개**. 각 4~6초. "첫째, 둘째" 같은 열거 도입구 없이 바로 |
| 반전/현실 | 24~27초 | "환상 깨기" 항목 1문장 |
| 마무리 | 27~30초 | 행동 1개 + 저장·팔로우 유도 1문장(블로그 전체 글 안내) |

## 영상 스타일별 지시

**photoreal(실사)**: 각 beat 는 하나의 실사 장면(scene_prompt)을 가진다 — 페르소나의 하루 일과 속 장소·물건으로, 사람 얼굴 클로즈업보다 손·사물·공간 위주(생성 품질·초상권). 텍스트·로고 없음. 블로그 이미지 5장과 같은 세계관. 가능한 경우 2~3개 beat 는 이미지→영상 클립(5초)으로, 나머지는 정지 이미지 + 카메라 운동.

**motion(모션그래픽)**: 각 beat 는 모션 템플릿 하나를 쓴다 — `kinetic_full`(큰 글자 한 문장) / `bullet_card`(핵심 3개 카드) / `data_bars`(수치 비교) / `endcard`(마무리). 템플릿은 `templates/motion/*.html` 이며 설치자가 추가한 이름도 쓸 수 있다(`templates/motion/README.md`). 색은 브랜드 설정(config `brand.colors`, 없으면 기본 팔레트). 글자 수: kinetic_full 12자 이내, bullet_card 항목당 10자 이내.

## 자막 (captions)

- 내레이션을 그대로 자막으로. 한 자막 1줄 **12자 이내**, 2줄까지. 화면 하단 1/4, 안전 영역 안.
- 핵심 단어 1개만 강조색. 이모지 없음.
- 타이밍은 TTS 결과(timing.json)에서 문장별로 가져온다 — 손으로 추정하지 않는다.

## 썸네일 문구

04_copy.md 의 "숏츠 썸네일 문구"(12자 이내). 첫 프레임(훅 장면)에 큰 글자로 얹는다.

## 금지

- 블로그에 없는 사실·수치
- "안녕하세요 ○○입니다"로 시작 (훅이 먼저)
- 광고티 어휘(`copy.md` 목록), 최상급
- 배경음악을 대본에 넣거나 곡을 지정하기 — 배경음악은 설치자가 `assets/bgm/` 에 넣은 곡만 build 가 자동으로 작게 깐다(저작권).

## 출력

`script.json`
```json
{
  "duration_s": 30,
  "style": "photoreal",
  "thumbnail_text": "…(12자 이내)",
  "beats": [
    {"id": "hook", "narration": "…", "caption": "…", "scene_prompt": "…(실사)", "scene_query": "laptop cafe morning", "target_s": 3}
  ],
  "full_narration": "…(beats 를 이은 전체 문장)",
  "tts_text": "…(숫자를 한글로 푼 TTS 입력)"
}
```
produce 모드에서는 timing.json 을 보고 `plan.json`(샷 시작·끝이 빈틈없이 이어지고 합계 = duration_s)을 만든다. 스키마 검증은 `osmu.py video plan-check` 가 한다.
